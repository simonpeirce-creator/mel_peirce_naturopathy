# Mel Peirce Naturopathy marketing skills

Codex project skills in `.agents/skills`. Open this repository as a Codex workspace and invoke a skill by name, for example `$mel-content-planner`. Keep the folders together so each skill can find the shared profile and review reference. These are original Markdown instructions with no runtime dependencies.

| Skill | Role |
|---|---|
| `mel-business-context` | Maintain practice facts, source provenance and approvals |
| `mel-content-planner` | Plan two newsletter issues and companion posts |
| `mel-newsletter` | Draft welcome, editorial and offer emails |
| `mel-social-content` | Adapt approved material for Instagram |
| `mel-audience-growth` | Design signup and measure subscriber and offer interest |

Start by reviewing the business profile with Mel. Test the signup path and welcome delivery, then draft one newsletter and companion Instagram post. Use subscriber replies and waitlist interest to decide what paid offer to test. Track baseline subscribers, signups by source and sales when an offer is live.

[Review scenarios](tests.md) give example inputs and expected decisions.

Start with `$nz-sole-trader-admin` to establish the calendar and confirmed registrations. Use `$nz-sole-trader-tax` for a specific tax question. The skills link to official NZ sources and leave Mel's actual registrations, dates and liabilities open until confirmed.
