---
name: mel-onboarding
description: Onboard Mel or Simon into the practice's AI toolkit, work through the questionnaire in small batches, and turn answers or corrections into reviewable updates for the other skills.
---

Read [Intake and updates](references/intake.md) and the current [practice profile](../mel-business-context/references/profile.md). If available, read the latest approved operating facts or decision records supplied by the user. A prefilled questionnaire is a draft until Mel confirms its answers.

Start with the task at hand when it is clear. If the goal is unclear, offer to start with a task, answer a few questions, or use an existing questionnaire. Explain in plain language what the answer will help with and where it would be saved. Ask one question at a time in chat unless the user wants a short batch. Accept estimates, 'not sure' and skips. Give an example answer if a question is unfamiliar.

Return a short recap, any immediate action and the proposed profile changes with their sources and approval status. Ask Mel to confirm only items that materially affect the current workflow. Continue drafting with explicit assumptions where safe. Use the approved profile on subsequent tasks. Review corrections before updating a shared record, and propose a skill change only when a repeated test exposes a problem in its instructions.
